<details>
<summary><b>📖 О проекте</b></summary>

**Dynamic Island** — это приложение-оверлей для Android, воспроизводящее концепцию «динамического острова» iPhone: интерактивная область вокруг выреза камеры, которая показывает уведомления, медиаплеер, звонки, навигацию и другие события системы в компактной и развёрнутой форме.

В отличие от многих аналогов, здесь остров — это не просто красивая обёртка над уведомлениями, а **полноценный центр управления** с собственной системой настройки, дизайном **Luna Night** и встроенным **ИИ-ассистентом**.

</details>

<summary><b>⚠️ Информация о тестировании</b></summary>

## ✨ Возможности

<details>
<summary><b>🏝️ Остров</b></summary>

- **Компактный вид** — маленькая «таблетка» вокруг выреза камеры с текущим событием
- **Развёрнутый вид** — раскрывается по тапу в полноценную панель
- **Landscape-режим** — 4 варианта поведения в горизонтальной ориентации *(показывать / компактно / скрывать / скрывать + пилюли при уведомлениях)*
- **Анимации** — настраиваемая скорость для панелей, страниц, тоглов и переходов CC *(глобальный множитель + 5 категорий)*
- **Акцентные цвета** — 6 пресетов: `Янтарь` `Лазурь` `Фиалка` `Мята` `Роза` `Апельсин`

</details>

<details>
<summary><b>🔔 Уведомления</b></summary>

- **Перехват** — Уведомления из любых приложений отображаются в острове вместо системной шторки
- **Правила на приложение** — «Всегда», «Никогда» или по глобальной настройке
- **Группировка** — Стек аватаров при нескольких активных чатах
- **Быстрые ответы** — Inline-ответ через RemoteInput *(Telegram, WhatsApp, SMS)* или копирование + открытие чата *(VK, Instagram, Discord)*
- **Смарт-реплаи** — Генерация 3 вариантов ответа через LLM *(нужен API Key)*
- **Автоперевод** — Перевод иностранных сообщений *(нужен API Key)*
- **История** — До 1000 записей, до 14 дней, с группировкой, поиском и свайпом для удаления
- **Кастомные иконки** — Замена стандартной иконки приложения в уведомлениях
- **Скрытие иконок** — Через `icon_blacklist`, 28 позиций
- **Тихие часы** — В остров попадают только приложения из белого списка

</details>

<details>
<summary><b>📞 Звонки</b></summary>

- **Системные звонки** — приём/отклонение/завершение через PendingIntent диалога
- **VoIP-звонки** — Telegram, WhatsApp, Signal, Viber, Discord, Max, Google Meet, Zoom, Teams, Skype, Webex и др.
- **Разделение** — системные и VoIP звонки корректно отображаются параллельно
- **Детали** — счётчик времени, аватар, номер

</details>

<details>
<summary><b>🎵 Медиа</b></summary>

- **Плеер** — обложка, название, артист, прогресс-бар, seek *(компактный и развёрнутый вид)*
- **Управление** — play/pause, следующий/предыдущий, лайк/дизлайк *(через MediaSession + кастомные действия)*
- **Обложки** — из MediaSession, при отсутствии — из уведомления плеера *(актуально для YouTube)*
- **Мультисессии** — автоматический выбор активной

</details>

<details>
<summary><b>🧭 Навигация</b></summary>

- **Поддержка** — Яндекс.Навигатор, Google Maps, 2ГИС, Waze *(через AccessibilityService)*
- **Манёвры** — чтение расстояния, ETA, списка шагов маршрута
- **Автогашение** — если данных нет 6 секунд, остров сам убирает навигацию

</details>

<details>
<summary><b>🎧 Наушники</b></summary>

- **Анимация подключения** *(GIF или Canvas)* — FreeBuds, Pixel Buds, AirPods, Sony, Galaxy Buds
  > *Сейчас реализована только анимация Huawei FreeBuds 7i, в планах — единая для всех*
- **Раздельный заряд** L / R / кейс *(пока только для Huawei)*
- **Общий заряд** — через `BluetoothDevice.getBatteryLevel()` *(Android 13+)*

</details>

<details>
<summary><b>⏰ Будильники</b></summary>

- Отображение ближайшего будильника за 60 минут *(настраивается)*
- Обратный отсчёт в реальном времени
- Отключение/отложить на Android 12+ через `ACTION_DISMISS_ALARM` / `ACTION_SNOOZE_ALARM`

</details>

<details>
<summary><b>🔋 Системные пекки</b></summary>

- **Батарея** — подключение/отключение питания, низкий заряд
- **Режим звонка** — Normal / Vibrate / Silent
- **Монитор трафика** — скорости ↓/↑, трафик за сегодня

</details>

<details>
<summary><b>🎛️ Control Center</b></summary>

Открывается **долгим тапом** по острову.

- **Плитки:** Wi-Fi, Bluetooth, мобильная сеть, DND, фонарик, геолокация, NFC, авиарежим, экономия батареи, поворот, хотспот, запись экрана, поиск музыки *(аналог Shazam, работает через API Key)*, Quick Share
- **Слайдеры** яркости и громкости *(медиа, звонок, будильник)*
- **Перестановка плиток** — карандаш → меняйте/удаляйте иконки
- **Быстрые контакты** — 4 слота с аватарами и звонком в один тап
- **Быстрые приложения** — 4 слота с иконками
- **Карточка батареи** — заряд, ток, температура, время до полной зарядки
- **Температуры CPU/GPU** — из sysfs

</details>

## 🌙 Luna — ИИ-ассистент

<details>
<summary><b>🤖 Возможности ассистента</b></summary>

> Работает через **ваш API Key** любого ИИ-провайдера.

- **Function calling** — 50+ инструментов *(полный список ниже)*
- **Стриминг ответов** + озвучка (TTS)
- **Голосовой диалог** — непрерывный цикл «слушаю → думаю → говорю»
- **Wake word** — активация по фразе *(сейчас «Нафаня», в планах — «Луна» с возможностью смены)*, модель openWakeWord в assets
- **Barge-in** — прерывание озвучки началом речи
- **Vision-модель** для распознавания изображений *(отдельный endpoint/ключ)*
- **Профиль и стиль** — имя, город, стиль ответа *(кратко/сбалансированно/подробно)*, персона
- **Память** — авто-извлечение фактов о пользователе, retrieval по ключевым словам
- **Сжатие истории** — старые реплики сворачиваются в резюме
- **Авто-макросы** — запуск сценариев по фразе без обращения к LLM
- **Плагины** — пользовательские команды с параметрами в JSON-манифесте
- **Guardrails** — опасные действия *(звонок, SMS, POST-запрос)* требуют подтверждения в UI
- **Белый список HTTP-доменов** — для инструмента `http_request`
- **Журнал Luna** — история вызовов инструментов с аргументами и длительностью

</details>

## 🤖 Автоматизация

<details>
<summary><b>⚙️ Профили и макросы</b></summary>

- **7 профилей:** `Обычный` `Работа` `Игра` `Фокус` `Вождение` `Ночной` `Сон`
  - Каждый меняет яркость, громкость, DND, перехват уведомлений, авто-раскрытие, скорость анимаций, акцент
- **Авто-триггеры** — привязка профиля к событию *(питание, низкий заряд, наушники)*
- **Макросы** — цепочка вызовов инструментов, запускается фразой
- **Задачи по расписанию** — Luna сама задаёт вопрос и озвучивает ответ в указанное время

</details>
