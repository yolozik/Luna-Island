## 📌 Главный принцип

> **Мы не собираем, не храним и не передаём ваши персональные данные на сторонние серверы.**  
> Всё, что делает приложение, происходит **локально на вашем устройстве**. У вас есть полный контроль над своими данными.

---

## 📊 Какие данные обрабатываются и как

### 🔔 Уведомления
Приложение запрашивает доступ к прослушиванию уведомлений (`NotificationListenerService`) для их отображения в «Динамическом острове».
*   **Что происходит:** Текст уведомлений, имена отправителей и аватары временно обрабатываются в оперативной памяти устройства.
*   **Хранение:** История уведомлений сохраняется **только локально** в базе данных устройства (до 1000 записей / 14 дней) и может быть очищена вами в любой момент.
*   **Передача:** Данные уведомлений **никогда не отправляются** разработчику или третьим лицам.

### ♿ Accessibility Service (Служба специальных возможностей)
Приложение использует Accessibility Service исключительно для чтения данных навигации (Яндекс.Навигатор, Google Maps, 2ГИС, Waze).
*   **Что происходит:** Считываются текстовые блоки с расстоянием, временем прибытия (ETA) и названиями манёвров.
*   **Хранение:** Данные не сохраняются, а используются только для отображения в реальном времени.
*   **Передача:** Информация не покидает ваше устройство.

### 🔓 Root-доступ
Для полноценной работы функций Control Center (переключение Wi-Fi, Bluetooth, DND и т.д.) приложение может запрашивать Root-права.
*   **Что происходит:** Выполняются системные команды для изменения настроек.
*   **Безопасность:** Приложение не получает доступ к вашим личным файлам, паролям или банковским данным. Root используется только для управления системными тогглами.

### 🌙 Luna — ИИ-ассистент
Для работы ИИ-ассистента вы **самостоятельно** добавляете API Key (OpenAI, Anthropic, Google и др.).
*   **API Key:** Хранится в защищённом хранилище вашего устройства (EncryptedSharedPreferences). Разработчик **не имеет доступа** к вашему ключу.
*   **История диалогов:** Сохраняется локально в базе данных. Вы можете отключить сохранение или очистить историю в настройках.
*   **Передача данных:** Текст ваших запросов и ответов передаётся **напрямую** выбранному вами ИИ-провайдеру (например, OpenAI). Разработчик приложения в этой цепочке не участвует и не видит ваши диалоги.
*   **Vision-модель:** Изображения, отправляемые на распознавание, передаются напрямую в API выбранного вами провайдера.

### 🌐 Интеграции (Погода, Новости, Календарь)
Приложение использует сторонние API (OpenWeather, GNews) для получения информации.
*   **Передача данных:** Отправляются только технические запросы (например, координаты города для погоды). Ваши личные данные не передаются.
*   **Контакты и Календарь:** Доступ запрашивается только для отображения событий и быстрого набора номера. Данные не покидают устройство.

## 🗄️ Хранение и удаление данных

| Тип данных | Где хранится | Как удалить |
|---|---|---|
| История уведомлений | Локальная БД (Room/SQLite) | Настройки приложения → История → Очистить |
| История диалогов Luna | Локальная БД | Настройки Luna → Память → Очистить |
| API-ключи | EncryptedSharedPreferences | Удаление приложения или сброс настроек |
| Резервные копии (ZIP) | Память устройства (по вашему выбору) | Удалить файл вручную |
| Логи и диагностика | Локальный кэш | Настройки → Диагностика → Очистить логи |

> **Важно:** При удалении приложения все локальные данные (история, настройки, ключи) удаляются безвозвратно.

---

## 🛡️ Безопасность

*   Приложение не передаёт данные по незащищённым каналам (используется HTTPS).
*   Для инструмента `http_request` в Luna существует **белый список доменов**, чтобы предотвратить случайную утечку данных.
*   Опасные действия (звонки, отправка SMS, POST-запросы) требуют **явного подтверждения** в интерфейсе (Guardrails).
